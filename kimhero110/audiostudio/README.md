# audiostudio

NAS（Docker）上运行的自托管 **MP3 / 有声书标签清洗工具**。扫描音乐库 → 按规则生成纯预览变更 → **自动整文件备份后原地应用** → 不满意**一键字节级回滚**。可选对接 MusicBrainz（默认关闭）。

## 主要功能

- **标签清洗**：广告/来源标记（`[www.xxx]`、中文下载站 `唯心阁/vxg点cn/微鑫公众号` 等，共用一套正则，也作用于文件名）、乱码修复（强证据门控，不误伤中文）、去垃圾帧、自动补缺、默认保留 ID3v2.4
- **批量改名**（Bulk Rename Utility 风格）：规则栈（正则替换/文本替换/序号/大小写/前后缀/裁剪/扩展名）+ 实时预览 + 变更高亮；或按标签模板重建
- **封面管理**：嵌入 folder.jpg、去重、超阈值自动压缩、提取、人工标记替换被广告污染的封面、手动上传
- **有声书规则**：目录类型标注（自动/音乐/有声书）、作者-书名-分P schema、m4b 章节保留
- **媒体库平台预设**：AudioBookshelf（`{作者}/{书名}/NN - 章节.mp3` + 标签 schema）、Jellyfin/Emby
- **安全**：整文件备份 → 全格式字节级回滚；LIFO 回滚限制；回滚前 hash 校验；崩溃后续跑/回滚；原子写；CSRF + 登录限流 + IP 白名单

## 使用

1. 启动容器，打开 `http://NAS_IP:8080`，用 `APP_PASSWORD` 登录
2. **库**：添加目录（挂载的音乐/有声书根）→ 扫描
3. **文件夹**：勾选目录 → 预览清洗 / 按 AudioBookshelf 整理
4. 预览确认后 **应用**（自动备份）；不满意 **回滚**

## 说明

- `PUID/PGID` 必须匹配音乐库文件属主（Unraid 默认 `nobody:users` = 99:100）
- 应用前整文件备份在 `/mnt/user/appdata/audiostudio/data/backups/`，默认保留最近 3 批
- 详细文档见 GitHub：https://github.com/kimhero110/audiostudio
